🧠 Reminder Web App (React + Flask)

A simple full-stack web app that allows users to manage reminders — built with React for the frontend and Flask for the backend.
This project demonstrates a clean client–server architecture, RESTful APIs, and cross-origin communication using Flask-CORS.

 Features

🗓️ Create and view reminders

🔔 Send meeting or event notifications

⚙️ RESTful API built with Flask

🎨 Modern React frontend with responsive design

🔄 Real-time data exchange between frontend and backend
